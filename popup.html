弹窗授权：插件 ID 已固定。点「授权」会按 oauth-config.js 自动核对回调地址，再用自己的 Google 账号同意。客户端 ID 写在该文件里，用户不用各自填写。
服务账号：也可以只导入服务账号 JSON。这样要把文件夹共享给该邮箱。密钥只留在本机。不支持域范围委派。
404 排查：仅 Apps Script 模式。script.google.com → 打开项目 → 部署 → 管理部署 → 复制网页应用 URL → 粘贴到上方保存 → 测试连接 → 授权。
批量删除：在云端硬盘面板勾选文件后点「删除所选（移入回收站）」，可在回收站恢复。
访问口令：Apps Script → 项目设置 → 脚本属性，添加 DRIVE_MANAGER_TOKEN。不填则与未设置口令的后端兼容。
自动更新：只检查 christiancagfr-alt/Google-Drive-manager 的正式发布。扩展不会自动覆盖安装。私有仓库需本机只读令牌。
图片/视频放大：仅在谷歌表格、谷歌文档中生效（云端文件夹页面不启用，避免挡操作）。悬停 Drive 链接/缩略图可放大；视频可预览，Alt+点击固定后可播放，Esc 关闭。
